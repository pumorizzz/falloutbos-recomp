# Register combiner states of Fallout: Brotherhood of Steel that get a pixel shader of their own.
#
# What this is: nv2a_gpu_shaderc (the toolkit's build step, see src/d3d/nv2a_gpu_shaders.cmake,
# NV2A_GPU_RC_KEYS in CMakeLists.txt) compiles one specialised ps_rc per line below; the D3D11
# back end draws a combiner state that matches a line with that shader and every other state
# with the general one (and names it in fobos.log: "combiner state with no shader of its
# own"). A specialised shader holds only that program's code, so a GPU that assigns registers
# by the worst path of a shader (the Steam Deck) runs it much faster.
#
# Format: nv2a_gpu_rc_key.h of the toolkit, one `rc n=... ctl=... prog=... fin=... tex=...
# sN=...` line per state; '#' and empty lines are comments. Most pixels first.
#
# How to add states: run with RECOMP_GPU_RASTER_RC_STATS=1 (a table of every state with its
# draws and pixels in the 10 s [GPURAST] report), or take the "combiner state with no shader
# of its own" lines from fobos.log, and paste the `rc ...` text here; rebuild. Copy the new
# line into deps/xboxrecomp/tests/nv2a_gpu_backend/rc_keys_test.txt as well, so the toolkit's
# tests prove that shader bit for bit on WARP.
#
# Collected 2026-11-18 on a PC: the boot route to Carbon, Ruby's bar, the Tutorial and a
# live pass through the Tutorial, the bar and Carbon; 9 states, the same in all four.
